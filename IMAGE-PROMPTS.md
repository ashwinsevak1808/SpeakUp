# Image guide: Your English website

All photos live in `public/images/`. Right now each one is a green placeholder tile with its filename on it.
**To go live: generate an image, save it with the exact same filename (.jpg), and overwrite the placeholder.**
No code change needed. Any size works (the site crops to fit), but use the sizes below for best quality.

## Style prefix (paste at the START of every prompt for a consistent look)

> Professional editorial photograph, natural window light, soft and clean, shallow depth of field,
> realistic Indian people (age 20-40), modern bright interior with white and light-green accents,
> subtle green tones in clothing or props, authentic candid expression, no text, no logos, no watermarks,
> no illustration, no cartoon, photorealistic, 35mm, high resolution.

Tip: generate people looking natural and unposed. Avoid stock-photo "thumbs up" poses. Check hands and faces.
