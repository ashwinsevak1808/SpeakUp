# SpeakUp Post Studio

Instagram posts and reel covers with photos you generate in Gemini.

1. **Double-click `Open Studio.command`** (or open `index.html`). On first run macOS may ask to confirm: right-click > Open.
2. Under each post click **Copy Gemini prompt**, paste it into Gemini and generate the image.
3. **Drag the image onto the post**, or save it in `images/` with the name shown (e.g. `images/join-1.png`).
4. Click **Download PNG**: a finished 1080 x 1350 post (1080 x 1920 for reels), ready for Instagram.

Captions: see `../posts/CAPTIONS.md`. Reel scripts are under each reel card.
